# Termux

[← Índice del manual](index.md)

MAGI corre también dentro de Termux, en Android: el mismo programa que en el
escritorio, compilado para `aarch64-linux-android`.

## Instalar con el `.deb` {#instalar-con-el-deb}

```bash
pkg install ./magi-ssh_1.6.1_aarch64.deb
magi diagnostico
```
